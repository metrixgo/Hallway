This is a horror parkour game built using Unity. It contains 5 different level types, lots of obstacles, and a jumpscare, so be ready for that.

How to play: Open https://metrixgo.itch.io/hallway and you can immediately play it in the browser! I suggest, however, click the "Download Now" button to play it locally to avoid unexpected browser errors.
